## 阅读约定

- “已验证”只表示列出的行为在记录的环境通过，不表示整项功能或所有部署形态完成
- “部分”表示已有行为证据，但仍有明确缺口；“待补”表示没有相应功能案例
- 解析/转发 spy、运行时边界替身、真实网络、独立进程、真实 WinUI、生产 App 分开登记
- 以下是按现有功能的首轮责任审计；逐公共成员、Windows 平台分支和所有异常组合的细化仍需推进
- Windows x64 的通过不能代替其他 OS/架构，也不能代替最终 App MSIX 的安装与激活
- 已增加 WSL Arch Linux x64 的 Core/Application/CommandLine/Mobile/CLI JIT/Blazor 实际结果；Windows 与 Linux 首轮失败及修复报告分别保留，不据此声明所有平台完成
