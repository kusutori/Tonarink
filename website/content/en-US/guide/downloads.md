# Choose a download

| Build | Recommended for |
| --- | --- |
| Native AOT MSIX | Try this first. It starts faster, uses fewer resources, and includes Windows integrations. |
| Standard MSIX | The stable fallback if Native AOT stutters noticeably on your device. |
| Portable | No installation, but packaged integrations such as Windows Share are unavailable. |
| Widgets | Testing only; the Windows 11 widget remains in development. |

Choose x64 by default, or ARM64 for Windows on Arm devices.
